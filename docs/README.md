# Multilingual-IRT — project page

Static GitHub Pages site for "Extending Item Response Theory for Efficient and Meaningful Multilingual Evaluation".

## Deploy
1. Push `index.html` and the `static/` folder to a repo (e.g. `multilingual_irt` or `<user>.github.io/multilingual-irt`).
2. Repo Settings → Pages → deploy from branch `main`, root folder.
